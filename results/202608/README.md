# Tables of the write-up, CRSP vintage 202608

The tables the notebooks wrote to `outputs/` on 7 October 2026 (vintage 202608 of Ken French's files), copied here with their provenance record so that every figure in the README, the note, the companion page and the dashboard resolves to a file at a named commit. `provenance_french.json` records the download date, the SHA-256 of each zip and the vintage. Each notebook regenerates its files from French's library at run time, into `outputs/`, which is the run directory; French revises history, so a later vintage will not reproduce every digit. The file names carry the notebook's subject and the vintage: `replication_*` and `extended_sample_*` from notebooks 03 and 07, `benchmark_*` from 08, `covariance_estimators`, `daily_to_monthly_scaling`, `bias_by_period` and `minimum_variance_costs` from 10, `optimiser_*` from 11, `rolling_evaluation*` and `active_returns` from 12, `attribution_*` and `factor_means_*` from 13.

Version 2, module A: `factor_objective_*` from notebook 14, written on 8 October 2026 on the same vintage (the curves at the three report months, the feasibility of the budgets over the 566 months with the sample estimator's stationary objective, one capped step, and the worked month at 2026-08).
